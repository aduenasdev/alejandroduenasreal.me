## Por qué

El capítulo de Pangeanic como profesional externo (mar 2024 → abr 2026) decía solo «microservicios, herramientas
internas en Next.js y despliegue en AWS». No contaba para qué entró: hacerse cargo de servicios en producción y
migrarlos.

## Qué cambia

- Texto del capítulo de 2024 en `src/data/perfil.ts`: mantenimiento, cambios y soporte de los servicios en Java/Spring
  Boot; APIs nuevas en Java y Next.js; desarrollo web en Next.js y React; migración de APIs de Java 8 a Java 21 y de Java a Python, con Docker en AWS, y la
  infraestructura y los despliegues al día.
- Etiqueta del capítulo: «+ Migraciones Java 8 → 21 y a Python».
